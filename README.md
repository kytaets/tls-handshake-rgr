# РГР: імітація TLS/SSL рукостискання (базовий варіант)

Клієнт і сервер на Node.js (TCP, модуль `net`), без сторонніх бібліотек, тільки вбудований `crypto`.

1. Клієнт надсилає `client_hello` з випадковими 32 байтами.
2. Сервер відповідає `server_hello` зі своїми випадковими 32 байтами і публічним ключем RSA-2048.
3. Перевірку сертифіката в CA пропущено (базовий варіант).
4. Клієнт генерує premaster (48 байтів), шифрує публічним ключем сервера (RSA-OAEP, SHA-256), сервер розшифровує приватним.
5. Обидві сторони рахують сеансовий ключ HKDF-SHA256(premaster, salt = client_random || server_random).
6. Обидві сторони надсилають `finished` з текстом «готовий», зашифрованим сеансовим ключем (AES-256-GCM).
7. Далі чат і передача файлів шифруються сеансовим ключем.

## Запуск

```
node server.js
node client.js
```

Команди клієнта: звичайний текст — повідомлення; `/file secret.txt` — передати файл; `/tamper текст` — відправити пошкоджений пакет (сервер його відхилить).
